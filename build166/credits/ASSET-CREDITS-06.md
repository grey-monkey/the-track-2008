# Revision 06 asset provenance

The new rider is derived from MakeHuman's standard human and clothing assets, released under CC0. It replaces the original revision 05 sculpture; it is not claimed as wholly original geometry.

Sources:
- [MakeHuman standard asset pack and license](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)
- [MakeHuman license distinction between code and assets](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md)
- [MPFB Blender integration](https://github.com/makehumancommunity/mpfb2)

Used assets: MakeHuman human basemesh and proportion targets, game_engine rig/weights, male_casualsuit06 clothing and ambient-occlusion texture, shoes05 geometry and diffuse texture, short02 hair geometry and diffuse texture, and low-poly eyes. The source material headers identify the standard asset release as CC0. MPFB is used as a build tool in Blender; its GPL application code is not included in the game.

Project work includes body proportion settings, clothing cropping and trouser variants, inverse-kinematic tow/carve/crouch poses, foot-weight corrections, finger curl and grip tracking, pose export, painted material lighting and wardrobe colors. Runtime textures are resized/encoded derivatives of the source textures. No Photoshop editing or motion capture is claimed.

The authored poses are exported as compact morph targets for the browser. The editable rigged source, with textures packed, is assets/Rider-study.blend. These are a shared character foundation, not finished individual crew likenesses.

The Mercedes remains the project's Blender model. Revision 06 adds full red rear lens faces and restrained warm lamp cores. Sky, brush and woodland provenance remains documented in ART-LANGUAGE.md and earlier asset notes.
