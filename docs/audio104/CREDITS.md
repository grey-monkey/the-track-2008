# Audio 104 — source credits and provenance

All effects are edited human recordings. No generated effects or synthesized ambience. Edits: mono conversion, 32 kHz resampling, filtering, normalization, trims and loop crossfades, documented in edits.json. Freesound inputs are public HQ MP3 previews, not lossless original WAVs. Original downloads stay outside the runtime package.

- **Car Engine Ignition Running and Turn Off** — qubodup. [CC BY 4.0](https://freesound.org/people/qubodup/sounds/147243/). Used for engine-idle / engine-load. Opel Astra 1.6 16V, Zoom H2. Not a W124 recording.
- **SkateRolling.wav** — Lanterr. [CC0](https://freesound.org/people/Lanterr/sounds/688733/). Used for wheel-roll / chatter. Recorded rolling loop; four board EQ/rate variants share this source.
- **skateboard grinding on concreate slab.wav** — 21100495. [CC0](https://freesound.org/people/21100495/sounds/655372/). Used for deck-scrape. Deck tail sliding on concrete.
- **Skateboarding Tricks** — VoiceBosch / SoundBiterSFX. [CC BY 4.0](https://freesound.org/people/SoundBiterSFX/sounds/746602/). Used for impact-1 / impact-2 / impact-3. Trimmed deck impact transients. Honor displayed CC-BY despite informal credit-optional description.
- **Damaged muffler 3 (parked car)** — Joseph SARDIN. [CC0](https://bigsoundbank.com/damaged-muffler-3-parked-car-s1571.html). Used for exhaust. Steady low-passed section; deliberately subdued.
- **Car on a Road** — Joseph SARDIN. [CC0](https://bigsoundbank.com/car-on-a-road-s1286.html). Used for car-tires. High-passed car-road recording; contains vehicle sound, not a separately miked tire-only recording.
- **Cicada 2, long** — Joseph SARDIN. [CC0](https://bigsoundbank.com/cicada-2-long-s2399.html). Used for cicada. Actual cicada; location/species not established. Do not claim Charlotte-specific authenticity.
- **Skateboard Powerslide** — Jacob Marcinczyk. [CC BY-NC 4.0](https://sonicdictionary.duke.edu/items/skateboard-powerslide.html). Used for wheel-slide. Recorded on an abandoned tennis court in Richmond, Virginia. Noncommercial prototype use only; replace/license before commercial use.
