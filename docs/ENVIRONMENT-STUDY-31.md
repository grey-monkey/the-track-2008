Replaced the disconnected side-opening patch with a single centered apron. The two open iron leaves share a 10.625 m paved entrance (2.5 lanes relative to the existing 8.5 m two-lane road), tapering smoothly into the original alignment. Removed the extra side opening and central monument from the carriageway layout; no median remains.

Removed the old flat entrance curb strip that was intersecting the new profile. A single rolled-curb sweep now follows the changing road width. Graded the underlying terrain and connected dirt shoulders to its actual mesh surface to stop intersecting earth facets. Moved the drain to the new gutter alignment. The pavement contact sampler now includes the apron triangles, so wheel support follows the displayed surface.

Validation: standalone inspection and ride bundles built; browser inspection of gate overview and drain/curb close-up; ride start with no browser errors. This is a local environment study, not a new public release or activated hazard system. Width is a proportional reconstruction from user direction, not a surveyed measurement.
