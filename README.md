# The Track: 2008 — Build 170

[Play](https://grey-monkey.github.io/the-track-2008/) · [Pintail drift preview](build170/comparison170.html) · [Previous published build](build169/playtest169.html?v=169)

The Pintail now has a dedicated arcade drift for Sally, Black and Dog: speed-gated entry, speed-dependent slide angles and grip, deliberate steering and smoother countersteer recovery. Boss and other boards retain their previous handling. THPS4 pre-switch poses inform the animation; sustained drift handling is a Track adaptation. Boss still collects 30 smoke hits across retries for his protected rainbow minute.

Includes the existing foreground selection framing, character movement, North Carolina terrain, material and world refinements. [Release notes](RELEASE-170.txt). Earlier builds remain available. [Asset credits](build170/credits/ASSET-CREDITS-09.md).
