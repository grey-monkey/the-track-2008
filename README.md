# The Track: 2008 — Build 166

[Play](https://grey-monkey.github.io/the-track-2008/) · [Second-Hand Smoke preview](build166/comparison166.html) · [Previous published build](build165/playtest165.html?v=165)

Only Boss can collect three of Sprad's smoke puffs to trigger Second-Hand Smoke. This changes the sky only: Boss keeps riding on the rope with normal gravity, without a backflip or launch. The illustrated clouds remain, with rainbow colors for 30 seconds and a six-second fade. Boss cannot collect Secret Spliff; Sally, Black and Dog still can.

Includes the intervening character, movement, world, North Carolina terrain, material, and selection-screen refinements. [Release notes](RELEASE-166.txt). Earlier builds remain available. [Asset credits](build166/credits/ASSET-CREDITS-09.md).
