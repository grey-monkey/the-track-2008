# The Track: 2008 — Build 165

[Play](https://grey-monkey.github.io/the-track-2008/) · [Second-Hand Smoke preview](build165/comparison165.html) · [Previous published build](build154/playtest154.html?v=154)

Boss can collect three of Sprad's smoke puffs to trigger Second-Hand Smoke: a backflip launch, recovering gravity, and a 30-second rainbow sky with the illustrated clouds retained. The sky fades back over six seconds.

Includes the intervening character, movement, world, North Carolina terrain, material, and selection-screen refinements. [Release notes](RELEASE-165.txt). Earlier builds remain available. [Asset credits](build165/credits/ASSET-CREDITS-09.md).
